# O Clone Digital — Painel de acompanhamento

> Este painel é o espaço de organização do projeto. A ideia ainda está em fase inicial: itens podem mudar e nenhuma possibilidade vira decisão sem confirmação.

## Como usar

Use um status por item:
- **💡 Ideia** — possibilidade anotada, ainda sem decisão.
- **🟡 A avaliar** — precisa ser discutida ou pesquisada.
- **🔵 Planejado** — decidido para uma próxima etapa.
- **🛠️ Em andamento** — trabalho iniciado.
- **✅ Concluído** — finalizado e conferido.
- **⏸️ Pausado** — fica guardado para depois.
- **❌ Descartado** — não será seguido, mantendo o registro para contexto.
