# Vídeos das aulas

Use esta pasta para organizar os vídeos das aulas do O Clone Digital.

## Como enviar

1. Abra a pasta `videos` no GitHub.
2. Selecione **Add file → Upload files**.
3. Envie o arquivo de vídeo e faça commit na branch `main`.

## Organização sugerida

Use nomes claros, por exemplo:

- `modulo-01-aula-01.mp4`
- `modulo-02-aula-01.mp4`

**Importante:** subir um vídeo para esta pasta apenas o armazena no repositório; isso não o adiciona automaticamente ao player da plataforma. Depois que enviar a primeira aula, me passe o nome/caminho do arquivo para integrarmos ao módulo correto.
